# 곡별 이미지 생성

배경 이미지 아래에서 선택 곡 또는 이미지가 연결되지 않은 곡의 생성 요청을 Markdown 파일로 저장합니다. 브라우저 다운로드 폴더에 저장되며 곡 제목, 원문 가사, 음악 폴더, 곡 ID가 포함됩니다.

기본 구도는 영화 스틸컷 느낌의 16:9 썸네일입니다. 제목만 상단/좌상단에 넣고 하단 35%는 자막을 위한 어둡고 단순한 여백으로 비웁니다. 곡당 한 장을 최종 채택합니다.

요청 파일을 Codex 대화에 전달해 생성과 시각 검수를 실행합니다. 로컬 앱 버튼은 요청 파일을 만들며 이미지 생성 서비스를 직접 호출하지 않습니다. Codex 이미지 생성은 온라인 기능입니다. 제목 철자, 비율, 가사 분위기, 하단 여백을 확인한 뒤 음악 폴더에 새 파일로 저장합니다. 기존 파일을 덮어쓰지 않습니다.

앱에서 폴더 다시 스캔(↻) 후 해당 곡의 배경 이미지로 선택합니다. 제목/가사가 변경되지 않았는지 확인하고, 이미지에 제목이 있으면 영상 스타일의 곡 제목 표시를 꺼서 중복을 피합니다.

현재 실곡 세 곡은 모두 이미지가 연결되어 있어 새 이미지를 자동 생성하거나 기존 이미지를 교체하지 않았습니다. 생성 결과의 품질 검수는 실제 생성 실행 시 진행합니다.
