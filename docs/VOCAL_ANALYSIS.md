# 보컬 분리와 누락 재인식

2026-09-12 변경. 기존 README/CODEX_HANDOFF의 보컬 분리 미구현 설명보다 이 문서가 우선합니다.

## 사용

음성 분석의 기본값은 **보컬 분리 후 분석**, **누락·의심 구간 자동 재시도 켜기**입니다.
Whisper 모델은 기존 `large-v3`, 장치는 기존 `CPU int8` 기본값을 유지합니다.
보컬 분리는 별도로 PyTorch가 사용 가능한 GPU를 자동 사용하며, 없으면 CPU로 동작합니다.
`원본 음악으로 분석`을 선택하면 분리를 생략합니다. 비교를 위해 재시도도 끌 수 있습니다.

처리 단계는 보컬 분리 모델 준비 → 보컬 분리 → Whisper → 원문 매칭 → 필요 시 원본 전체 비교 → 구간 재인식입니다.
음원은 로컬에서 처리합니다. 최초 공개 모델 다운로드에 인터넷과 추가 디스크 공간이 필요합니다.
분리가 실패하면 오류를 표시합니다. 성공한 것으로 위장하거나 사용자 모르게 원본 모드로 바꾸지 않습니다.

분리 모델: audio-separator 0.47.0 / BS-RoFormer `model_bs_roformer_ep_317_sdr_12.9755.ckpt`.
기본 설치: `install_audio_windows.bat`. 기존 `.venv`는 보존하고 새 `.venv-audio`를 사용합니다.
서버는 `LYRICFLOW_PYTHON` 지정값 → `.venv-audio` → 기존 `.venv` 순서로 선택합니다.
Python 3.11/3.12를 사용하세요. 다른 PC로 가상환경을 복사하면 경로가 깨질 수 있으므로 새 환경을 설치하세요.
`install_windows.bat`에도 기본 보컬 분석 환경 설치를 연결했습니다.

## 보존과 결과 해석

- 원본 음원·이미지·원문을 변경하지 않습니다. 최종 영상/미리보기의 음원은 계속 원본입니다.
- 분리본과 분석 캐시는 음악 폴더의 `.lyricflow-remotion/cache/` 아래에 저장합니다.
- 모델 파일은 앱의 `.lyricflow-studio/models/` 아래에 저장합니다.
- 분리본을 16 kHz mono로 변환하지만 무음·간주를 제거하지 않습니다. 원곡과 길이가 50 ms 이상 다르면 중단합니다.
- 분리는 별도 프로세스로 수행하고 종료 후 Whisper를 로드해 GPU 메모리 중복 점유를 줄입니다.
- 같은 음원 해시/분리 모델/라이브러리/분리 설정은 보컬 캐시를 재사용합니다. 캐시 WAV 해시도 확인합니다.
- 원본/보컬, 모델, 언어, 장치, 파이프라인 버전과 재시도 설정을 정렬 캐시에 반영합니다.
- 수동 잠금과 검수 완료 줄을 보존합니다. 나머지 줄은 새 분석으로 갱신하며, 이전 줄 목록은 기존 되돌리기 이력에 보존합니다.
- 분석 중 가사/음원이 바뀌면 기존 stale-result 검사가 결과 적용을 거부합니다.

실곡 비교에서 보컬 분리로 누락이 오히려 증가하는 곡을 확인했으므로, 재시도를 켰을 때 보컬 초벌에 누락/의심 표시가 있으면 원본 전체 인식도 비교합니다.
시간 확보 줄 수가 많고, 동률이면 의심 표시 없는 줄 수가 많은 쪽을 선택합니다. 정확도 확률이 아닌 자동 대응량 기준입니다.
원본이 선택되면 화면에 **분리 후 원본 비교 선택**이라고 표시합니다. 보컬 분리만 무조건 신뢰하지 않습니다.

선택한 초벌의 빈 줄과 의심 줄은 앞뒤의 정상 매칭 구간으로 범위를 제한해 다시 인식합니다.
주변 가사를 포함한 오디오 문맥을 주며, 긴 구간은 30초 중심 구간과 최대 양쪽 5초 문맥으로 나눕니다.
원문 가사를 Whisper 프롬프트로 주입하지 않습니다. 인식된 단어를 원곡 절대 시간으로 복원한 뒤 줄 순서를 검사합니다.
선택한 음원의 구간에서 충분한 대응이 없으면 다른 음원의 같은 구간을 다시 인식합니다.
새 후보가 기존 이웃 줄을 침범하거나 순서를 역전하면 채택하지 않습니다.

재인식으로 확보한 시간에는 **구간 재인식으로 찾음 · 청취 확인 필요** 표시가 붙습니다.
누락을 억지로 채우거나 가짜 균등 시간을 생성하지 않습니다.
시간이 생겼다는 것은 가창 위치의 최종 정확도를 증명하지 않습니다.
독립 음성 인식의 누락과 가사 매칭 실패를 항상 확정적으로 분류할 수는 없으며, 출력 JSON에 인식 단어/초벌 줄/재시도 후보를 남깁니다.

## 비교 검증

`scripts/compare_audio.py acceptance/real-songs-20260911 --device cuda`는
동일한 large-v3/GPU 설정으로 원본(재시도 끔)과 보컬(재시도 켬)을 비교합니다.
보컬 초벌 결과도 따로 저장하므로 분리 효과와 재시도 효과를 구분할 수 있습니다.
기존 `project.json`에는 적용하지 않으며 원본 음원과 프로젝트의 전후 해시를 검사합니다.
초기 실험: `acceptance/vocals-20260912/`. 최종 보호 장치 검증: `acceptance/vocals-final-20260912/TEST_REPORT.md`.
별도 출력 폴더는 `--output vocals-final-20260912`처럼 지정합니다. 자동 집계는 시간 확보 수와 후보 변화이며, 청취로 검증한 정확도가 아닙니다.
