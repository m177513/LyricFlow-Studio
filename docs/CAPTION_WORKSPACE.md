# 자막 검수 작업 화면 재설계 (2026-09-14)

이전 구현은 실제 편집기 워크플로 조사 없이 버튼과 드래그만 추가했다. 사용자가 지적한 두 줄 지그재그 배치, 분리된 선택 상태, 파형 부재를 개선했다.

확인한 공식 자료:
- Adobe: https://helpx.adobe.com/au/premiere/desktop/add-text-images/insert-captions/about-captions.html — 별도 자막 트랙과 Text 패널.
- Adobe tutorial: https://www.adobe.com/fi/learn/premiere-pro/web/subtitles — 클립 이동/끝점 조절. 구형 UI 안내이므로 현행 메뉴 배치 근거로 사용하지 않음.
- CapCut: https://www.capcut.com/resource/how-to-add-subtitle-in-capcut — 생성한 자막을 타임라인에 배치 후 문구/타이밍 편집.
- Movavi: https://www.movavi.com/support/how-to/how-to-add-subtitles-to-video-automatically/ — 자동 자막 생성 후 편집기에서 조정. 광고성 정확도 수치는 채택하지 않음.

실제 변경:
- 왼쪽 미리보기/선택 가사 편집, 오른쪽 가사 목록, 아래 단일 자막 트랙과 실제 원본 음원 파형.
- 기본 약 20초 구간 확대. 선택 가사로 이동, 줌 시 기준 위치 유지, 재생 따라가기, 눈금/파형 스크러빙.
- 자막 몸통 이동/끝점 트림, 6px 이내 인접 끝점/재생 헤드 스냅. Alt로 일시 해제.
- 시간 미지정 줄을 목록에서 선택하면 앞 가사 끝으로 재생 위치만 옮김. 가사 시간 자체는 추정해서 저장하지 않음.
- I/O로 시작/종료 기록. 둘 다 유효할 때 기존 revision 검사 PATCH로 저장. 미완성 구간은 미저장 표시.
- 선택한 문구/시간 편집, 구간 듣기, 확인 후 다음. 의심 필터에 맞춰 다음 미검수 줄 이동.
- 가사 선택 시 목록 내부만 스크롤. 곡/출력 설정은 접을 수 있는 우측 패널.

검증:
- npm test 54/54 PASS; typecheck / build PASS.
- 실곡 검증곡 D에서 원본 파형 로드와 시간 미지정 5번 선택 → 28.600초 커서 이동 확인. 원본/시간은 테스트로 수정하지 않음.
- 독립 브라우저 fixture: 미지정 줄 I에서 미저장, O에서 4000~5013 저장. 구간 2000~4000을 1566~3566으로 이동해 길이 유지. 오른쪽 끝을 인접 4000으로 스냅. 확인 후 다음은 2번으로 이동. 콘솔 오류 없음.
- 테스트가 실제 last-project 설정을 덮던 기존 부작용을 발견해 테스트 appRoot를 임시 폴더로 격리. 실제 최근 폴더 설정 복구.

한계: 전체 상용 편집기 재현이나 전체 음악 청취 검수 완료를 뜻하지 않는다. 파형은 원본 믹스의 첫 채널 피크 표시이며 가사 정답 위치를 보장하지 않는다. 브라우저에서 곡당 최초 한 번 음원을 읽어 파형을 계산한다.
