# 쇼츠 출력

곡을 선택하고 상단 **쇼츠 만들기**를 누릅니다. 원곡 기준 시작·끝 시간을 초 단위로 입력하거나, 현재 재생 위치 / 목록에서 선택한 가사 구간을 사용합니다. **세로 미리보기**로 확인한 뒤 **쇼츠 MP4 출력**을 누릅니다. 처리 상황에 MP4와 해당 구간 SRT가 표시됩니다.

- 1080×1920, 최대 180초. 선택 경계는 프로젝트 FPS의 프레임 단위로 반올림됩니다.
- 원본 음원·이미지·가사 시간·가로 영상 스타일은 변경하지 않습니다.
- 기존 가사 시간을 선택 구간 시작 기준으로 옮기고, 양끝에 걸친 가사는 경계에서 자릅니다. 원문 텍스트와 반복 가사는 보존합니다.
- 무보컬 곡은 자막 없이 출력합니다. 가사가 있는 곡은 기존 전체 곡 검수 조건을 통과해야 합니다.
- 시작/끝 선택값은 브라우저에 작업 폴더·곡별로 보관합니다.
- 세로 화면은 기존 이미지 맞춤 설정을 사용하며, 뒤에 흐린 배경을 채웁니다.

## 이 PC의 렌더 환경

기본 번들 FFmpeg가 종료 코드 3221225477로 충돌하여, 기존 제작에서 사용하던 호환 런타임을 `.lyricflow-studio/render-runtime.json`에 앱 기준 상대 경로로 연결했습니다. 서버가 시작할 때 읽는 로컬 설정이며 HTTP 요청에서 실행 경로를 받지 않습니다. 쇼츠는 공용 worker를 사용하고 선택 구간의 오디오를 합칩니다. 기존 개별 영상은 기존 worker 설정을 유지합니다.

## 검증 (2026-10-16 KST)

- 타입 검사, Player 빌드 통과.
- 기존 77개 + 쇼츠 3개 테스트 통과. Windows 기본 임시 폴더의 rename 권한 오류로 TEMP/TMP를 verification/shorts-temp로 지정해 실행.
- 실제 API → 작업 큐 → 1080×1920 H.264/AAC, 2.5초 MP4 및 SRT 출력 완료.
- 합성 신호의 원곡 1.0~3.5초를 출력하고 PCM 비교로 시작 위치 확인: 올바른 구간 MSE 110.36, 자르지 않은 구간 MSE 75665.00.
- 전체 영상·오디오 디코딩 통과. 실제 한글 자막 프레임 육안 확인.
- Chrome에서 구간 입력, 세로 미리보기, 역전 구간 차단, 출력 버튼 작동 및 완료 후 MP4/SRT 링크 표시 확인. 기존 작업 폴더로 복귀. 화면 기록: verification/shorts-ui.png.
- 합성 검증은 실제 노래의 기존 가사 정렬 정확도나 청취 검수를 대신하지 않습니다.
