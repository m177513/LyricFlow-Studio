### 테스트가 확인한 핵심

원문 및 소괄호 보존, 제작 태그 제거, 반복 후렴 발생 순서와 ID, 누락된 줄의 null 시간, 경계·역전·중첩 검사, 잠긴 수동 수정 병합, 입력/스타일에 따른 캐시 키, 원본 변경 감지, 검수되지 않은 출력 차단, SRT 밀리초, 플레이리스트 누적 프레임을 확인했습니다.

실제 Node HTTP 서버에서 원본 WAV를 ffprobe로 읽고 해시를 구했습니다. 수정 저장·재불러오기, 409 revision 충돌 거부, 오류 패치의 부분 변형 방지, 외부 Origin/토큰 없는 쓰기 차단, 경로 이탈 차단, 실제 오디오 Range 206/416, 미디어 키, 중단 작업 복구를 검사했습니다. 실제 브라우저에서 폴더 열기, `large-v3` 전체 재분석, 곡별 줄 수·확인 필요 수를 확인했습니다.

실패 후 큐 연속 처리 검사는 테스트에서 결정적으로 실패하는 worker를 주입한 단위 검사이며, 실제 Remotion 출력 성공을 대신하지 않습니다. 실제 MP4 출력은 아래 인수 증거에 별도로 기록했습니다. Suno parser 검사는 자체 HTML/JSON fixture이며 실제 Suno 사이트에서 가사를 가져온 검사가 아닙니다. Python 검사는 ASR의 실제 품질이 아니라 주어진 단어 시간과 원문을 연결하는 순수 로직만 검증합니다.
