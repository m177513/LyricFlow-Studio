# 제한과 미구현 항목

2026-09-12: 보컬 분리와 누락 구간 재인식이 구현되었습니다. 현재 설명은 `VOCAL_ANALYSIS.md`, 검증은 날짜별 `acceptance/` 보고서가 우선합니다. 아래 blocked 목록은 초기 제작 환경의 기록으로, 현재 PC의 설치 상태를 뜻하지 않습니다.

## 현재 환경에서 막힌 실행 검증

- [blocked] npm/Python 모델 의존성 설치: 이 제작 컨테이너의 외부 호스트 이름 해석·다운로드가 실패했습니다. Remotion Player 빌드, 실제 타입 검사, Whisper 추론, 모델 다운로드, Remotion MP4 출력은 검증하지 못했습니다.
- [blocked] 실제 브라우저 상호작용: Chromium에서 로컬 URL 탐색이 `net::ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되었습니다. 정책을 우회하지 않았습니다. HTTP API를 실제 실행한 검증과 브라우저 클릭 검증을 구분합니다.
- [blocked] 실곡 품질/Suno 현재 페이지: 사용자 실제 음원·현재 링크가 이 제작 작업에 제공되지 않았습니다. HTML parser와 ASR 순서 매칭의 합성 fixture 검사는 성공률·정확도 검증이 아닙니다.
- [blocked] Windows 설치, 네이티브 폴더 선택, 한글 글꼴 출력: Linux 제작 환경이므로 사용자 Windows PC에서 확인해야 합니다.

## 구현 범위상 포함하지 않은 것

별도 보컬 스템 수동 연결, WhisperX/언어별 CTC, 단어·음절 노래방 색 채우기, 정교한 오디오 파형/스펙트럼, 사용자 임의 선택 구간의 ASR 실행, 폴더 상시 감시, 데스크톱 설치형 패키징, YouTube 자동 업로드, OAuth/사용자 계정/클라우드 DB는 없습니다. 자동 보컬 분리와 누락·의심 구간 재인식은 `VOCAL_ANALYSIS.md`의 범위로 구현되어 있습니다.

현재 `hybrid`는 **선택 stable-ts 어댑터**이며, 실곡에서 개선된다고 검증하지 않았습니다. 공식 upstream은 2026-05-30 아카이브되었고 개발이 무기한 중단되었다고 명시되어 있습니다. 기본 ASR 처리와 분리했으며 유지보수 가능한 다른 엔진을 검토할 수 있게 해두었습니다. 출처: https://github.com/jianfch/stable-ts (2026-09-11 확인).

## 실제 사용 시 남는 판단

Suno에 저장된 원문과 실제 가창이 항상 같다는 가정은 하지 않습니다. 반복 횟수 변경, 실제 생략, 애드리브는 확인이 필요합니다. 같은 곡 제목의 다른 버전/리마스터/앞부분 트리밍은 자동으로 동등한 파일이라 판단하지 않습니다.

현재 원문 순서 매칭은 어휘 일치 기반의 보수적 초벌입니다. 독립 ASR이 통째로 빠뜨린 줄은 기본적으로 미정으로 둡니다. 실제 가창에는 정확히 있는 줄이라도 사람이 위치를 지정해야 할 수 있습니다. 반복 줄에는 검수 플래그를 붙이므로 초기에 검수량이 많을 수 있습니다. 보장되지 않은 시간 정확도 수치를 붙이지 않습니다.

긴 줄의 자동 줄바꿈은 가능하지만 화면 폭/한글 글꼴/두 줄 높이는 실제 출력에서 눈으로 확인해야 합니다. 현재 시스템 글꼴을 쓰므로 다른 PC에서 같은 모양을 보장하지 않습니다. 폰트 파일은 배포하지 않습니다.

썸네일에는 이미 텍스트가 있을 수 있습니다. 기본 자막 위치와 겹치면 하단 여백/크기를 조절해야 합니다. 썸네일의 텍스트를 자동 감지해서 피하는 기능은 없습니다.

로컬 앱은 한 번에 한 프로젝트를 여는 개인 작업용입니다. 다중 사용자·여러 서버 프로세스의 동시 쓰기를 지원하지 않습니다. 큐 동작 중 폴더 변경은 막습니다. 프로세스가 종료되면 대기 작업을 자동 재개하지 않고 중단으로 표시합니다.

파일명/이미지 매칭은 폴더 최상위 기준입니다. 파일 존재 및 등록 원본 경계는 검사하지만 지원 이미지가 실제 디코딩 가능한지는 Remotion 로딩 시 실패할 수 있습니다. 기본 브라우저 오디오 모드에서 일부 형식이 재생되지 않으면 WAV/MP3로 검사하고, 최종 원본 지원 여부는 렌더러에서 확인해야 합니다.

플레이리스트는 곡별 정수 프레임에 맞춰 이어 붙입니다. 각 경계에서 최대 한 프레임 미만의 여유가 발생할 수 있어 샘플 단위의 무간격 믹스/크로스페이드는 지원하지 않습니다. 파생 입력 사본을 출력 폴더에 보존하므로 디스크 여유를 확인해야 합니다.
